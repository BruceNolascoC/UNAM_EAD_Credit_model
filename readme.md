# UNAM Project EAD Credit Model
This repository is used as a workspace for the development and evaluation of an Exposure At Default model based on a sample dataset provided by the course instructor.

The repository shows the scripts and/or notebooks used for the exploratory data analysis, model training and selection, evaluation and post-hoc analysis.

The base dataset is located at `dat.csv` and the associated data dictionary is located at `data_dictionary.csv`.
